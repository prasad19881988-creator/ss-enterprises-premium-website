SS Enterprises Premium CMS Website

This package contains:
- index.html: public website
- admin.html: secure management panel
- config.js: one-time Supabase project configuration
- supabase-schema.sql: one-time database setup
- script.js/styles.css/logo.png

After the one-time Supabase setup and deployment, projects and team profiles can be changed from /admin.html without editing GitHub files.

Important: use Supabase Auth for the admin account and keep the admin credentials private.
