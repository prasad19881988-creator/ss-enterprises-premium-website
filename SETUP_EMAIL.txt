SS ENTERPRISES — PROFESSIONAL STAFF LETTER EMAIL SETUP

What this package adds:
1. Admin Panel button: "Email Letter + T&C"
2. Offer Letter PDF is generated from the currently selected employee.
3. The original 5-page Terms & Conditions PDF is attached unchanged.
4. Email is sent directly to the employee's email stored in Staff Management.
5. Sender is: SS Enterprises <ssenterprisesservice@poton.me>
6. API key is kept server-side in a Supabase Edge Function; it is NOT placed in admin.js.
7. Non-offer letters are sent as one PDF. Offer letters are sent with two PDF attachments.

FILES
- admin.html        -> replace existing admin.html
- admin.js          -> replace existing admin.js
- SS_Enterprises_Terms_and_Conditions.pdf -> upload to the same website/root folder
- supabase/functions/send-letter-email/index.ts -> create this Supabase Edge Function

SUPABASE EDGE FUNCTION
Function name:
send-letter-email

Deploy this function in your Supabase project. The function uses the currently logged-in Supabase user and only permits app_users roles owner/admin/hr.

SUPABASE SECRETS REQUIRED
RESEND_API_KEY = your Resend API key

SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY are normally available to Supabase Edge Functions automatically. Do not put the service-role key in admin.js or the browser.

RESEND DOMAIN
Before production sending from ssenterprisesservice@poton.me, add and verify poton.me in Resend. Resend will provide the DNS records that must be added at your domain/DNS provider. Do not invent DNS values; use the exact records shown in your Resend dashboard.

HOW STAFF EMAIL WORKS
1. Open Admin Panel.
2. Staff Management -> select/add employee.
3. Put the employee's real email in the Email field and save.
4. Letters -> select the employee.
5. Select Offer Letter and Generate Letter.
6. Click Email Letter + T&C.
7. The system sends directly to that employee's email.

IMPORTANT
- The email button does NOT open WhatsApp or the phone's mail app.
- It sends through the server-side email function.
- The original Terms & Conditions PDF is attached as a separate 5-page PDF, so its page layout/signature/stamp are not reflowed by the email PDF generator.
- The company signature/stamp used in the Offer Letter still comes from Company Profile.
