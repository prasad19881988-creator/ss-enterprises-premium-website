SS ENTERPRISES - PROFESSIONAL PAYMENT COLLECTION SYSTEM

1. Run the complete RUN_THIS_IN_SUPABASE_SQL_EDITOR.sql in Supabase SQL Editor.
2. Upload all files from this folder to GitHub, replacing matching files.
3. Render will deploy automatically.
4. Admin > Payment Settings: enter SS Enterprises payment details and UPI ID.
5. Admin > Field Collections: create professional customer collection records and receipts.
6. Later, change Account Type from Savings to Current and update bank/UPI details. Old collection records remain unchanged.

IMPORTANT: Use only payment details authorized for your business. A UPI QR is generated from the UPI ID you enter.
